# Spells Reference Guide 2

This document provides a reference table of all spell cards in **Wizards of the North**, detailing each spell's Name, Color, Mana Cost, and Description.

## Arena Spells Table

| Name | Color | Mana Cost | Description |
| :--- | :---: | :---: | :--- |
| **Lightning Strike** | Red | `{R}` | Deals 2 damage to target creature or enemy tower. |
| **Fireball** | Red | `{R}{R}` | Deals 3 damage to target creature or structure. |
| **Vision** | Blue | `{U}` | Draw 2 cards from your deck. |
| **Counterspell** | Blue | `{U}{U}` | Cancel an enemy spell or ability target. |
| **Clone** | Blue | `{U}{U}{U}` | Create a copy of target friendly creature on an adjacent tile. |
| **Mana Drain** | Black | `{B}{B}` | Steal 2 mana from opponent's mana pool. |
| **Downgrade Land** | Black | `{B}{B}` | Downgrade target enemy territory level by 1. |
| **Destroy Land** | Black | `{B}{B}{B}` | Destroy target enemy territory, making it unowned. |
| **First Strike** | White | `{W}` | Target friendly creature gains First Strike in battle. |
| **Upgrade Land** | White | `{W}{W}` | Upgrade target controlled territory level by 1. |
| **Mana Boost** | Green | `{G}` | Gain +3 colorless mana for this turn. |
| **Create Land** | Green | `{G}{G}` | Claim target unowned adjacent tile as controlled territory. |
| **Trample** | Green | `{G}{G}` | Target friendly creature gains Trample in battle. |

## Deck 1 Variant Spells Table

| Name | Color | Mana Cost | Description |

| **Counterspell** | Blue | `{U}{U}` | Counter opponents spell. |
| **Clone** | Blue | `{U}{U}` | Clone a creature. |
| **Mana Drain** | Blue | `{U}{U}` | Drain 3 random Mana from your opponent. |
| **Downgrade Land** | Blue | `{U}{U}` | Upgrades a land to the next level, L4 -> L3, L3 -> L2 and L2 -> L1. |
| **Destroy Land** | Blue | `{U}{U}{U}` | Destroy a Land L1 of your choosing. |
| **First Strike** | Blue | `{U}{U}` | Gives target creature First Strike. |
| **Upgrade Land** | Blue | `{U}{U}` | Upgrades a land to the next level, L1 -> L2, L2 -> L3 and L3 -> L4. |

| **Create Land** | Blue | `{U}{U}{U}` | Transform Grass or Wasteland into a Land L1 of your choosing. |
| **Trample** | Blue | `{U}{U}` | Gives target creature Trample. |
