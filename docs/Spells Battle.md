# Spells Battle

## Trample
- Card text: Target friendly creature gains Trample in battle.
- How it should work: Gives target creature the keyword ability Trample for the remainder of the battle.

## First Strike
- Card text: Target friendly creature gains First Strike in battle.
- How it should work: Gives target creature the keyword ability Trample for the remainder of the battle.

## Lightning Strike
- Card text: Deals 2 damage to target creature or enemy tower.
- How it should work: Gives target creature 2 damage.

## Fireball
- Card text: Deals 3 damage to target creature or tower.
- How it should work: Gives target creature 3 damage.

## Clone
- Card text: Create a copy of target creature both friendly or hostile.
- How it should work: Add a copy of target creature and add to players army.

## Freeze
- Card text: Freezes target creature until end of battle.
- How it should work: Disable and dim the card, the creature can't attack or block for one turn.

## Flying
- Card text: Target friendly creature gains Flying until end of battle.
- How it should work: Target creature gains the keyword ability flying

## Disenchant
- Card text: Removes target enchanment.
- How it should work: Can remove any earlier cast spells, when it is dropped on a spell badge it is removed.

## Strength
- Card text: Target friendly creature gains +2/+2 until end of battle.
- How it should work: Target friendly creature gains +2/+2 until end of battle.

## Fog
- Card text: Attackers turns end directly.
- How it should work: Show an info modal and then end the attackers turn without any attacks.

## Fear
- Card text: Target creature gets -1/-1 until end of battle.
- How it should work: Target creature gets -1/-1 until end of battle.

## Heal
- Card text: Heal target creature for 2 damage.
- How it should work: Heal target creature for 2 damage.

## Poison
- Card text: Target creature gets poisoned.
- How it should work: Takes 1 damage each turn for 2 turns then the poison badge is removed.

## Regenerate
- Card text: Target friendly creature gains Regenerate until end of battle.
- How it should work: Heals 1 damage every turn, if the creature has no damage nothing happens.

## Web
- Card text: Removes target creatures flying ability until end of battle.
- How it should work: Remove the flying ability.
