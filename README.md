# Wizards of the North 🧙‍♂️✨

**Wizards of the North** is a tactical hexagonal board game of magical domination and territory conquest built with React, TypeScript, and Vite.

---

## 🎮 Game Overview

In *Wizards of the North*, rival Archmages battle across a hex grid to capture elemental territories, channel specialized mana, summon creatures, cast powerful spells, and conquer the enemy Wizard Tower.

### 🌟 Key Features

- **Hexagonal Tactical Grid:** Navigate and capture dynamic hexagonal map tiles.
- **5-Color Mana Economy:** Gather specialized mana from controlled lands:
  - 🌾 **Plains (White / W):** Life, defense, and order.
  - 🌲 **Forests (Green / G):** Growth, beasts, and raw power.
  - 🌋 **Mountains (Red / R):** Fire, aggression, and direct damage.
  - 🔮 **Swamps (Black / B):** Decay, corruption, and sacrifice.
  - 🏰 **Towers (Blue / U):** Arcane intellect, wizardry, and manipulation.
- **Wizard Progression:** Level up your Archmage to boost mana generation and unlock greater magical potential.
- **Creatures & Combat:** Deploy units with unique movement, attack power, and defense capabilities to siege enemy lands and defend your tower.
- **Spellcasting:** Turn the tide of battle with territorial enhancements, creature buffs/debuffs, and direct damage spells.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18+ recommended)
- `npm`, `pnpm`, or `yarn`

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/rikardsk/wizards-of-the-north.git
   cd wizards-of-the-north
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

---

## 📜 Available Scripts

- `npm run dev` - Start local development server with hot module replacement (HMR).
- `npm run build` - Type-check with TypeScript and build the production bundle into `dist/`.
- `npm run preview` - Preview the production build locally.
- `npm run test` - Run the test suite with Vitest.
- `npm run lint` - Run Oxlint across the project.
